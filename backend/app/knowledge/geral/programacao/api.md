# API

Nível: Geral
Matéria: Programação
Palavras-chave: API, endpoint, requisição, resposta, integração, backend, frontend

API significa Interface de Programação de Aplicações.

Uma API permite que sistemas diferentes conversem entre si de forma organizada.

Exemplo simples:

Um frontend pode enviar uma pergunta para uma API de backend. O backend processa a pergunta e devolve uma resposta.

Conceitos principais:

- endpoint: endereço da API;
- requisição: pedido enviado para a API;
- resposta: retorno da API;
- JSON: formato comum usado para troca de dados;
- método HTTP: ação usada na requisição, como GET ou POST.

Explicação para iniciante:

Pense em uma API como um atendente. Você faz um pedido seguindo um formato combinado, e o atendente entrega uma resposta seguindo outro formato combinado.
