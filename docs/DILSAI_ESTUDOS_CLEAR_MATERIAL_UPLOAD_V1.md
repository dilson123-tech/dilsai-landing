# DilsAI Estudos — Clear Material Upload V1

## Status

DILSAI_ESTUDOS_CLEAR_MATERIAL_UPLOAD_V1

## Objetivo

Adicionar botão para limpar material simples carregado na tela cheia do DilsAI Estudos.

## Escopo

Incluído:

- botão Limpar material;
- limpeza do input de arquivo;
- limpeza do textarea de contexto quando o conteúdo veio de arquivo carregado;
- remoção dos metadados locais loadedFileName e loadedFileSize;
- atualização do status visual.

Fora do escopo:

- PDF;
- OCR;
- armazenamento no servidor;
- histórico de materiais.

## Regra de UX

O botão deve limpar somente o material carregado via arquivo simples. O restante do chat deve permanecer intacto.

## Próximo passo recomendado

Após validar este ciclo, avançar para upload PDF simples ou melhorar o card visual do material carregado.
