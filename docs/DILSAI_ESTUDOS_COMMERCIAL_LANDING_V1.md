# DilsAI Estudos — Commercial Landing V1

## 1. Objetivo

Registrar a evolução da página pública do DilsAI Estudos para apresentação comercial inicial.

Este ciclo não altera a inteligência do produto, backend, OCR, upload, fallback ou fluxo principal de estudos.

## 2. Escopo

A landing foi ajustada para posicionar o produto como plataforma educacional com IA para:

- estudos;
- informações;
- revisões;
- preparação para testes e provas;
- uso de material próprio;
- PDF textual;
- imagem com OCR;
- PDF escaneado via OCR;
- fonte/contexto quando disponível;
- fallback seguro.

## 3. Alterações principais

Foram ajustados:

- título da página;
- meta description;
- Open Graph e Twitter metadata;
- hero comercial;
- CTAs;
- seção de recursos;
- aviso educacional;
- seção de piloto comercial;
- CTA final;
- texto desatualizado sobre PDF escaneado;
- estilos comerciais da landing.

## 4. Limites preservados

A página não promete:

- aprovação;
- nota;
- resposta perfeita;
- OCR perfeito;
- substituição de professor;
- substituição de escola;
- fraude em prova.

## 5. Segurança de produto

O ciclo preserva a diretriz do produto real:

- não refazer arquitetura;
- não mexer na lógica de chat;
- não mexer no backend;
- não mexer no OCR;
- não mexer no fallback;
- não iniciar RAG;
- não criar login ou cobrança neste PR.
