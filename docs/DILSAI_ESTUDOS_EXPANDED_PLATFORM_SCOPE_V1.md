# DilsAI Estudos — Expanded Platform Scope V1

## 1. Objetivo deste documento

Este documento amplia oficialmente o escopo do DilsAI Estudos.

A partir deste marco, o DilsAI Estudos deve ser tratado como uma plataforma ampla de estudos, dúvidas, revisão, simulados, explicação de questões e apoio educacional, com foco em alunos do ensino fundamental, ensino médio, cursos técnicos, concursos e universidades.

O produto continua sendo real e comercial, não projeto de brincadeira.

## 2. Visão ampliada do produto

O DilsAI Estudos deve evoluir de um chat simples para uma plataforma de aprendizado com IA.

A visão correta é:

DilsAI Estudos é um professor digital com IA para tirar dúvidas, explicar conteúdos, ajudar em exercícios, revisar matérias, montar simulados, interpretar materiais enviados pelo usuário e orientar estudos de forma clara, responsável e segura.

O foco é:

- estudo real;
- explicação didática;
- precisão;
- organização por matéria;
- resposta com contexto;
- base de conhecimento;
- upload de materiais;
- simulados;
- revisão;
- preparação para provas;
- apoio ao aluno sem incentivar cola ou fraude.

## 3. Diretriz principal: amplitude com responsabilidade

O DilsAI Estudos pode cobrir muitas áreas, mas não deve prometer saber tudo com certeza absoluta.

Regra oficial:

Quando a IA tiver conhecimento geral suficiente, ela pode responder de forma didática.

Quando a pergunta depender de apostila, prova, edital, regra específica, professor, instituição, legislação, norma técnica ou material de aula, a IA deve pedir contexto ou responder com aviso de incerteza.

Quando houver material enviado pelo usuário, a IA deve priorizar esse material.

Quando não houver base suficiente, a IA deve dizer claramente que não encontrou informação suficiente.

## 4. Chat grande estilo ChatGPT

A janelinha flutuante atual é útil para suporte rápido, mas não é suficiente para estudo pesado.

O produto deve evoluir para uma tela grande de conversa, estilo ChatGPT, com:

- área ampla de mensagens;
- histórico de conversa;
- seletor de nível de ensino;
- seletor de matéria;
- seletor de modo de estudo;
- campo para contexto/material;
- upload de imagem;
- upload de PDF;
- upload de arquivo de texto;
- respostas longas e organizadas;
- botão para limpar conversa;
- botão para gerar resumo;
- botão para criar simulado;
- botão para explicar passo a passo.

Diretriz:

A janelinha pode continuar como atalho, mas a experiência principal de estudo deve ser uma tela grande.

## 6. Modos oficiais de estudo

O produto deve manter e ampliar os modos existentes.

### 6.1 Modo Professor

Explica com calma, usando exemplos e linguagem adaptada ao nível do aluno.

### 6.2 Modo Direto

Responde de forma curta, objetiva e prática.

### 6.3 Modo Passo a passo

Resolve junto com o aluno, mostrando o raciocínio.

### 6.4 Modo Revisão

Gera resumo, tópicos principais, pontos importantes e perguntas de fixação.

### 6.5 Modo Simulado

Gera questões, alternativas, gabarito e explicação.

### 6.6 Modo Fonte Segura

Responde priorizando material enviado pelo usuário ou base cadastrada.

### 6.7 Modo Explicar questão

Recebe uma questão, foto, print ou texto e explica o caminho para resolver.

### 6.8 Modo Plano de estudo

Monta um plano por tempo disponível, nível e objetivo.

## 7. Upload de imagem, print, PDF e texto

O DilsAI Estudos deve permitir que o usuário envie materiais de forma explícita.

Tipos desejados:

- imagem;
- print;
- foto de exercício;
- PDF;
- TXT;
- DOCX futuramente;
- texto colado no chat.

Uso correto:

- o aluno envia uma questão;
- a IA lê ou recebe o texto;
- a IA explica;
- a IA mostra o raciocínio;
- a IA pode criar questões parecidas;
- a IA pode resumir o material.

## 8. Captura de tela: limite ético e técnico

O produto não deve ter captura escondida, invisível, furtiva ou usada para burlar prova, avaliação, monitoramento ou sistema de terceiros.

Diretriz obrigatória:

A captura de tela, se existir no futuro, deve ser sempre explícita, visível e autorizada pelo usuário e pelo navegador/sistema operacional.

Opções aceitáveis:

- botão "Enviar print";
- upload manual de imagem;
- colar imagem da área de transferência;
- seleção de arquivo;
- captura via recurso oficial do navegador, com permissão clara do usuário;
- OCR de imagem enviada voluntariamente.

Opções proibidas:

- captura escondida;
- captura sem consentimento;
- modo stealth;
- leitura de tela sem aviso;
- ferramenta para cola em prova ao vivo;
- burla de ambiente escolar, vestibular, concurso ou sistema de fiscalização;
- automação para responder prova em tempo real sem autorização.

Resumo:

O DilsAI Estudos deve ajudar a estudar, explicar e treinar. Não deve ser ferramenta de fraude.

## 9. Ajuda com provas: posicionamento correto

O produto pode ajudar com provas de forma ética.

Permitido:

- estudar antes da prova;
- gerar simulados;
- corrigir exercícios;
- explicar questões antigas;
- revisar conteúdos;
- ensinar resolução passo a passo;
- identificar erros;
- montar plano de revisão;
- explicar uma prova depois que ela foi feita;
- criar questões parecidas para treino.

Não permitido como proposta de produto:

- responder prova ao vivo de forma escondida;
- incentivar cola;
- burlar fiscalização;
- esconder uso da IA;
- prometer aprovação;
- substituir aprendizado por fraude.

Frase oficial:

O DilsAI Estudos é uma ferramenta de aprendizado e preparação, não uma ferramenta de cola.

## 10. Base de conhecimento e precisão

Para ser vendável, o produto precisa evoluir para base de conhecimento.

Fases recomendadas:

### Fase 1 — Base simples por arquivos internos

- materiais em Markdown ou texto;
- separação por nível;
- separação por matéria;
- busca simples por palavras-chave;
- injeção de contexto no prompt;
- resposta segura quando não encontrar base.

### Fase 2 — RAG com embeddings

- dividir documentos em trechos;
- gerar embeddings;
- buscar trechos por similaridade;
- usar os trechos no prompt;
- retornar fontes;
- apontar de qual material veio a resposta.

### Fase 3 — Upload de materiais por usuário

- aluno envia PDF;
- sistema extrai texto;
- sistema cria base temporária ou permanente;
- IA responde com base no material do aluno.

### Fase 4 — Base premium

- apostilas próprias;
- cursos;
- conteúdos licenciados;
- trilhas;
- simulados;
- questões comentadas.

## 11. Política de resposta com fonte

Quando a resposta vier de base cadastrada ou material enviado, a IA deve indicar:

- matéria;
- nível;
- fonte;
- trecho ou referência;
- confiança;
- aviso quando a base for insuficiente.

A IA não deve fingir que consultou fonte quando não consultou.
